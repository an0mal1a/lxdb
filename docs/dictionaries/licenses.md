# Licenses and attribution

The generated attribution distinguishes source-specific obligations. Kaikki-derived Wiktionary text is CC BY-SA 4.0/GFDL; LibreOffice documents its Spanish spelling dictionary as GPLv3+, LGPLv3+ or MPL 1.1; `wordfreq` code is Apache-2.0 and its data files are CC BY-SA 4.0. The Spanish WordNet/MCR source must be checked by snapshot because wordnet distributions vary.

Do not redistribute a generated dataset without retaining its `ATTRIBUTION.md` and verifying every downloaded snapshot's bundled license.
