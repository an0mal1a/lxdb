# Output files

- `dictionary.lxdb`: validated LXDB 0.1 binary.
- `manifest.json`: language, profile, format, source/license declarations, normalization and relation policy, counts and digest.
- `build-report.json`: parsed/rejected/merged counts, graph statistics and per-phase durations.
- `ATTRIBUTION.md`: source URLs, license declarations and reuse notes.
- `rejected-entries.jsonl.zst`: optional rejected-entry audit trail, a valid Zstandard stream of JSONL records.
